About ALA MC

ALA MC was a Vanilla Minecraft Survival Server aimed for compatibility on low end devices while still allowing an overall great for everyone. The server used to allow cracked accounts.

The server has been hosted on a Lenovo ThinkStation E30 running Windows Server 2022, An HP Compaq 5200 Pro running windows server, previously windows 10. Below is the old server ip.

The former Rules of ALAMC

Failure to comply may result in a kick or ban

  1. NO Hacking
  2. Don't be an annoyance. there are other people who want to have a good time
  3. Treat other people's builds with respect.
  4. Do not try to crash the server in any way
  5. This is NOT an anarchy server
  6. You can have conflict with other players but do not destroy or steal from random people.
  7. Have fun!

Dynamic Map

The server used the dynmap plugin allowing for a real-time view of the server map. You can see the locations of players in real time. There is a isometric view of the map availible. Along with that you can chat with players on the server.

What determines if you are seen on the map?

You are seen on the map unless you are crouching, under something or in the dark.
